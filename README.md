# Список дел

Это приложение для составления списка дел, созданное с помощью Vue.js. В проекте демонстрируется использование Vue Router и компонентов Vue для управления списком задач, включая добавление, удаление и пометку задач как завершенных. Приложение состоит из двух страниц:
 1. **Домашняя страница**:  отображает заголовок и ссылку для перехода на страницу списка дел.
 2. **Страница списка дел**:  позволяет пользователям возвращаться на домашнюю страницу, добавлять задачи, отмечать их как завершенные и удалять. Здесь также есть кнопки, позволяющие помечать все задачи как выполненные и удалять все задачи.

## Функции
 - **Добавление задачи**: введите текст в поле ввода и нажмите кнопку "Add to the list".
 - **Управление задачами**:
   - **Чекбокс**: отметьте задачи как завершенные - эти задачи будут перечеркнуты.
   - **Кнопка удаления**: удаляет отдельные задачи из списка.
   - **Кнопка "All done"**: помечает все задачи как завершенные.
   - **Кнопка "Delete all"**: удаляет все задачи из списка.
 - **Динамический список**: задачи нумеруются, и нумерация автоматически корректируется при удалении задач из списка.
 - **Пустое состояние**: выводит сообщение, когда список пуст.

## Используемые технологии
 - **Vue.js**: JavaScript-фреймворк для создания пользовательских интерфейсов.
 - **Vue Router**: управляет навигацией между домашней страницей и страницей списка дел.
