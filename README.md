# Список дел

Проект представляет собой SPA на **Vue.js** с двумя маршрутами: приветственным экраном и списком дел.

## Стек технологий
![Vue.js](https://img.shields.io/badge/vue.js-%2335495e.svg?style=for-the-badge&logo=vuedotjs&logoColor=%234FC08D)
![Vue Router](https://img.shields.io/badge/Vue%20Router-42B883?style=for-the-badge&logo=vue.js&logoColor=white)

## Веб-сайт
Вы можете создать свой список дел [здесь](https://afkeomre.github.io/todo-list/).
Если вы хотите увидеть, как это работает, посмотрите [скринкаст](https://drive.google.com/file/d/1zmKI2aaynbGC32YA5X3Wrpde1Qq8H9qL/view).

## Функции
- Добавление задачи  
- Отметка задачи как выполненной  
- Удаление задачи  
- Завершение всех задач одним действием  
- Очистка всего списка  
- Динамическая нумерация задач  
- Отображение сообщения о пустом списке  

## Настройка проекта

### Установка зависимостей
```
npm install
```

### Компиляция и горячая перезагрузка для режима разработки
```
npm run serve
```

### Компиляция и минификация для продакшена
```
npm run build
```
